# [클간사 시안] 꿈디도 별관 — 설계 의도 요약서

- 발신: 클간사 (Claude)
- 수신: 안간사 (참조: 지간사·제간사·워크간사)
- 일자: 2026년 11월 8일
- 시안 파일: `claude_annex_proposal.html` (단일 파일, 더블클릭으로 열림)

---

## 1. 한 줄로

별관은 '프로그램 목록'이 아니라 **뜰을 둘러싼 ㅁ자 별채**입니다. 현관에서는 할 일을 **문장**으로 고르고, 뜰 가운데 **우물**에서 이번 주 말씀을 한 번 길어 올리면 모든 방이 그 말씀을 들고 열립니다.

## 2. 화면 구성 (위에서 아래로 한 장)

| 자리 | 하는 일 |
|---|---|
| **현관** | "평안하십니까, ○○ 님." 인사와 오늘 날짜·교회력·다가오는 절기를 한 문장으로. 그 아래 **"무엇을 하시렵니까?"** — 주보 예배 순서지처럼 `문장 ······ 방 이름` 아홉 줄. 한 번 누르면 그 프로그램으로 바로 갑니다. |
| **우물가** (목양 사역 도우미) | ① **이번 주의 우물**: 본문·말씀의 한 줄·전할 주일을 적어 '길어 올리기'. ② **주일로 건너가는 징검다리**: 월→주일 일곱 돌. 돌을 누르면 그날 들를 방(말씀을 들고 열리는 문패)과 '요일마다 적어 둘 한 줄'. 주일 돌은 도구 없이 예배와 시편 118:24 한 절. ③ **마음에 품은 이름**: 이번 주 기도·심방할 분, 기도함/연락함/찾아뵘 표시. |
| **별관 안내도** | 쪽빛 도면. **말씀채(북)·돌봄채(동)·다음세대채(남)·살림채(서)** 네 채가 뜰을 둘러쌉니다. 방을 누르면 **문패**(하는 일 + 들어가기). 뜰 가운데 우물에 이번 주 말씀이 보입니다. 아래 **짓는 터**에 앞으로 지을 방. |

방 배치: 말씀채(설교 준비실·주석 서고·내 설교 곳간) / 돌봄채(성도 명부실·번역실) / 다음세대채(교회학교 교사실·교육과정 자료실·가정예배 식탁) / 살림채(주보·행정 공방·헌금·재정 장부실[곧 문 엶]) / 짓는 터(모바일 주보실·절기 현수막실·목회력 달력실).

## 3. 타사 틀과 다른 점 (공문 차별화 원칙에 대한 답)

| 흔한 틀 | 꿈디도 별관 |
|---|---|
| 왼쪽 프로필·D-day·할 일 사이드바 | 사이드바 없음. 위에서 아래로 읽는 한 장. 날짜는 숫자 카운트가 아니라 교회력 문장 |
| 우측 6개 자리 탭 | 개수 제한 없는 '방'. 기능 이름이 아니라 공간 이름, 네 채로 묶음 |
| 3단계 홍보 배너 | 없음 |
| 프롬프트 조립기, 결론/근거/할일/되묻는질문 | AI 조립 화면 없음. 대신 **한 말씀이 한 주를 꿰는** 구조 |
| 대시보드·위젯·슬롯·D-day | 현관·우물가·징검다리·문패·짓는 터 |

## 4. 어르신 목회자를 위한 장치

- 기본 글씨 18px, 머리띠의 **가 가 가**로 세 단계 확대(기억됨). 단추는 손가락 크기(48px 안팎).
- 매주 보는 **주보 순서지** 모양이라 처음 봐도 읽는 법을 압니다. 설명서 대신 한 문장: "문장을 누르시면 그 방으로 바로 갑니다."
- 합쇼체, 영어·약어 없음. 휴대전화에서는 안내도가 채별 목록으로 바뀝니다.
- 키보드 이동과 초점 표시, '움직임 줄이기' 설정 존중, 어두운 화면 자동 대응.
- 적은 말씀·이름·메모는 그 컴퓨터 브라우저에만 저장, 밖으로 보내지 않습니다.

## 5. 새 방 들이기 (확장)

스크립트의 `ROOMS`에 한 줄을 더하면 안내도·문패에 함께 들어섭니다.

```js
{ id: 'finance', wing: 'w', name: '헌금·재정 장부실', program: '작은교회 투명 재정·헌금 수첩',
  file: 'kkumdido_finance_studio.html', status: 'open', line: '…', does: ['…'] }
```

- `status`: `'building'` → 짓는 터 / `'soon'` → 채 안에 '곧 문 엶' / `'open'` → 문 열림
- `wing`: `n` 말씀채, `e` 돌봄채, `s` 다음세대채, `w` 살림채
- 현관 문장은 `ERRANDS`, 징검다리 요일은 `WEEK.rooms`에 id만 넣으면 됩니다.
- 한 채에 방이 늘어도 칸이 자동으로 나뉩니다. 채가 너무 길어지면 다섯째 채(별채)를 `WINGS`에 더하는 쪽을 권합니다.

## 6. 연동 규약 (안간사 배포 때)

1. **이용증**: `<body data-kkd-studio="true">` + 하단 `<script src="kkumdido-shield.js"></script>` 포함됨. 인사 이름은 `window.kkumdidoPass.getCard().name`, 머리띠 '이용증' 단추는 `kkumdidoPass.open()`.
2. **shield.js 손볼 곳**: 배포 파일명을 `kkumdido_annex.html`로 할 경우 `STUDIO_PATTERNS`에 `'kkumdido_annex'`, `getCurrentPageLabel()`에 별관 이름을 넣어 주십시오.
3. **우물 규약 (한 말씀 한 주)**: 이번 주 말씀이 있으면 모든 방 링크 뒤에 `?kkd_ref=룻기%202%3A12`가 붙고, 같은 값이 `localStorage['kkumdido_annex_well_v1'] = {ref, gist, sunday, savedAt}`에 있습니다. 각 스튜디오가 첫 화면에서 이 값을 읽어 본문 칸을 채우면 완성입니다. 읽지 않아도 지금처럼 그냥 열립니다.
4. **배포 설정**: 스크립트 맨 위 `BASE`(프로그램 파일 경로 앞부분), `LIBRARY_HOME`(본관 주소). 주소에 `design_contest`가 들어 있으면 시안 모드(이동 대신 안내 알림)로 돕니다.
5. **저장 열쇠**: `kkumdido_annex_well_v1`, `…_well_history_v1`, `…_names_v1`, `…_daynotes_v1`, `…_fontscale_v1`.

## 7. 시안에서 정해 둔 것 (확인 필요)

- 기념일 기준: 어린이주일 5월 첫째 주일, 어버이주일 둘째 주일, 맥추감사주일 7월 첫째 주일, 종교개혁주일 10월 마지막 주일, 추수감사주일 11월 셋째 주일. 교단 기준이 다르면 `notableDays()`만 고치면 됩니다.
- 헌금·재정 장부실: 청지기 장부 v1.0이 폴더에 있으나 공문에 '추가될 것'으로 되어 있어 '곧 문 엶'으로 둠.
- 12번 설교AI 주간사역 변환 스튜디오는 공문 목록에 없어 넣지 않음. 넣는다면 말씀채에 한 줄.
- 글꼴: Hahmlet(제목·문장) + Pretendard(안내). 인터넷이 없으면 기본 글꼴로 보입니다.

## 8. 별도 보고: shield.js 개인정보 (안관장 확인 요망)

시안 작업 중 `kkumdido-shield.js`를 읽다가 본 것입니다. 가입자 이름과 계정(이메일·전화)이 **공개 서버**(ntfy.sh 공개 토픽, emqx 공개 MQTT 브로커)로 전송되고, 토픽 이름이 공개 JS 파일 안에 그대로 있어 **아는 사람은 누구나 명부를 읽을 수 있는 구조**입니다. 관리자 PIN도 같은 파일에 평문으로 적혀 있습니다. 지인 개방 전에 손보시기를 권합니다. (별관 시안은 이 통로로 아무것도 보내지 않습니다.)
