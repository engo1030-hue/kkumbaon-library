🔒 [안심 보장 공지] 올리시는 설교 원고는 꿈디도 서버나 운영진에게 단 한 글자도 남지 않습니다!
이곳에 추가·작성하시는 모든 설교문은 외부 인터넷 서버로 전송(업로드)되지 않으며, 오직 현재 접속하신 본인 컴퓨터(브라우저 내부 저장소 IndexedDB)에만 100% 독립 보관됩니다. 꿈디도 운영진이나 다른 이용자는 절대 볼 수 없으니 안심하고 나만의 설교 곳간으로 편하게 정리하세요.
📖 내 설교문 작성·추가 및 백업 보관 (내 컴퓨터 단독 저장 · 서버 미전송)
• 지원 파일 형식: 한글 표준 문서(.hwpx), 워드(.docx), 문자형 PDF(.pdf), 텍스트(.txt, .md)
• 형식 안내: 구형 한글(.hwp)은 직접 읽지 못하므로 한글에서 [다른 이름으로 저장 → 한글 표준 문서(.hwpx)] 또는 .docx로 변환 후 넣어주세요. PDF 열람·추출은 최초 1회 인터넷 연결이 필요하며, 글자가 없는 스캔(이미지) PDF는 문자 인식이 지원되지 않습니다.
• 보관 안내: 추가·수정한 원고는 외부 서버 전송 없이 현재 브라우저 저장소(IndexedDB)에만 자동 보관됩니다. 다른 컴퓨터·새 브라우저로 옮기시거나 영구 소장하실 때는 [💾 내 곳간 백업] 파일을 내려받아 보관하세요.
