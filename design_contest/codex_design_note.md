# 지간사 디자인 공모전 시안 · 사역의 길, 도구 서가

- 대상: 『꿈디도 교회 지원 프로그램 별관 & 목양 사역 도우미』
- 제출일: 2026년 11월 8일
- 결과물: `codex_annex_proposal.html` (화면·스타일·동작을 담은 단일 HTML)

## 핵심 설계

첫 화면의 질문은 **“오늘 어떤 사역을 하시나요?”**입니다. 도구 이름을 기억하지 못해도 설교 준비, 교인 돌봄, 주보 제작, 교회학교 준비 중 지금의 일을 누르면 곧장 해당 도구로 갑니다. 이 네 가지 첫 클릭 아래에는 사역의 흐름을 따라 도구를 안내하는 **목양 사역 도우미**, 그리고 현행 프로그램을 목적별로 모은 **도구 서가**를 두었습니다.

| 층위 | 사용자가 하는 일 | 화면의 반응 |
|---|---|---|
| 바로 시작하기 | 자주 쓰는 네 가지 일을 고름 | 해당 도구로 바로 이동 |
| 목양 사역 도우미 | 말씀 → 사람 → 예배 → 배움 중 현재 사역을 고름 | 설명과 해당 도구 링크를 즉시 교체 |
| 도구 서가 | 이름 또는 `심방`, `주보`, `가정예배` 같은 일을 검색 | 9개 현행 도구와 서가를 실시간으로 거름 |
| 자라는 서가 | 앞으로 추가될 네 도구의 쓰임을 살핌 | `준비 중` 안내창을 표시 |

서가를 ‘말씀과 설교’, ‘교인과 가정’, ‘예배와 소통’, ‘다음 세대’로 나누어 새 프로그램도 알맞은 곳에 한 장의 카드로 추가할 수 있게 했습니다. 예고된 재정·헌금 수첩, 모바일 주보·홈페이지, 절기 배너, 연간 목회력은 현행 도구와 분리해 출시된 것처럼 보이지 않게 했습니다.

## 꿈디도다운 화면과 접근성

밝은 종이색, 녹색 서가, 펼친 책의 간결한 그림을 사용했습니다. 좌측 개인 프로필·일정·할 일 사이드바, 우측 여섯 탭, 단계형 홍보 배너, 프롬프트 조립기는 두지 않았습니다. 컴퓨터가 낯선 사용자에게 프로그램의 기능표보다 **지금 할 일과 다음 한 번의 클릭**이 먼저 보이도록 했습니다.

화면은 데스크톱·태블릿·휴대전화 너비에 맞춰 서가 열 수와 사역의 길 배치를 바꿉니다. 좁은 화면에서는 길을 한 줄씩 읽게 하고 버튼 높이와 작은 글자를 키웠습니다. 키보드 본문 건너뛰기, 초점 표시, 검색 단축키(`/`), 큰 글자 전환, 검색 결과 음성 안내, 움직임 감소 설정을 포함했습니다. 외부 글꼴·이미지·프레임워크를 요구하지 않습니다.

## 링크와 이용증 연동

- 공문의 `<body data-kkd-studio="true">` 및 `<script src="kkumdido-shield.js"></script>` 요구를 그대로 반영했습니다.
- 별관 파일을 지정된 `design_contest` 폴더에서 열면 현재 꿈디도 본관 폴더의 현행 도구 9개, 본관, 이용증 스크립트로 상대 경로를 연결합니다. 본관 루트에 배치할 때는 같은 폴더의 파일명으로 연결합니다.
- 도구 이동은 기존 `kkumdidoPass`의 이용증 상태와 로그인 창을 사용합니다. 이용증 스크립트가 없거나 아직 로드되지 않았으면 이동을 막고 안내합니다. 시안에 인증 키·비밀번호·가짜 로그인·인증 우회 코드는 없습니다.
- 별관 자체는 교적, 설교 원고, 재정 정보를 저장하지 않습니다. 큰 글자 선택만 브라우저에 보관합니다.
- 실제 Google·Kakao 로그인 완료 여부는 정식 배치 환경에서 기존 이용증 연동을 통해 확인해야 합니다. 로컬 파일로 열었을 때의 로그인 동작은 브라우저의 `file:` 정책에 영향을 받을 수 있습니다.

## 검수 및 적용 범위

공문 원문과 꿈디도 본관의 실제 파일 구성을 대조했습니다. 현행 도구 9개와 본관·이용증 스크립트의 존재, 상대 경로, 중복 ID, 화면 요소와 동작 연결, 인라인 JavaScript 구문을 정적으로 확인했습니다. 현재 작업 환경의 브라우저 보안 정책이 로컬 `file:` 주소 열기를 차단하여 화면 렌더링·실제 클릭·로그인 완료는 직접 검증하지 못했습니다. 정식 배치 전 실제 브라우저에서 데스크톱과 휴대전화 화면, 이용증 로그인, 도구 이동을 최종 확인해야 합니다.

이 시안은 별관의 화면과 길찾기 경험을 제안합니다. `준비 중` 네 프로그램의 기능 또는 출시 상태를 주장하지 않습니다.
