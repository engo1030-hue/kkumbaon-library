# 꿈바온 디지털 도서관 · 성경 세계 탐험 홀

## 여는 방법

폴더 안의 `index.html`을 더블클릭하면 시작됩니다.

## 이번 판의 핵심

- 지도를 화면의 중심으로 크게 배치했습니다.
- 마우스 휠·두 손가락 확대와 드래그 이동을 지원합니다.
- 49개 성경 장소를 도시·지역·호수·섬·산으로 나누어 표시했습니다.
- 장소를 누르면 이미지 미리보기와 짧은 소개가 먼저 열립니다.
- `도시 이야기 펼치기`를 누르면 성경 사건, 관련 본문, 연결 문헌이 이어집니다.
- 도시명·인물명·성경 구절로 검색할 수 있습니다.
- 구약·신약 필터와 지역별 빠른 이동을 지원합니다.
- 작은 화면에서는 카드와 지도가 세로로 자연스럽게 재배치됩니다.

## 자료 표기

- AI로 제작한 도시 복원 이미지는 화면 안에 `상상 복원도`로 분명히 표시했습니다.
- 현재의 유적·풍경 사진은 작가와 이용 조건을 출처 창에 기록했습니다.
- 지도는 Natural Earth의 현대 지리 자료를 바탕으로 하며, 고대 국경선이나 확정된 여행 경로를 뜻하지 않습니다.
- 위치에 학술적 논의가 있는 장소는 소개글에서 그 점을 밝혔습니다.

## 보존 원칙

기존 꿈바온 디지털 도서관 원본은 수정하지 않았습니다. 이 폴더가 새 탐험 홀 완성본입니다.
